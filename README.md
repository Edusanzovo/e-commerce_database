# 🛒 Projeto Ecommerce SQL

Este projeto consiste na modelagem, criação, população e consulta de um banco de dados relacional para simulação de um **e-commerce** utilizando **MySQL**.

O objetivo é praticar conceitos importantes de banco de dados como:
- modelagem relacional
- chaves primárias e estrangeiras
- relacionamentos 1:N e N:N
- integridade referencial
- normalização
- consultas SQL com `JOIN`, `GROUP BY`, `SUM`, `COUNT`, entre outros.
